# 에셋 라이선스 기록

게임에 들어가는 모든 외부 에셋(타일셋, 스프라이트, 폰트, 효과음, BGM)은 추가할 때 이 표에 기록한다. `/credits` 페이지는 이 문서를 기준으로 만든다.
- 허용 라이선스: CC0, OFL(폰트), CC BY(표기 의무 이행 시). 그 외 라이선스는 사용 전에 검토한다.
- 같은 화면 안에서는 한 계열의 에셋으로 스타일을 통일한다(SPEC §15).
- 직접 만든 에셋도 "자체 제작"으로 기록한다.
