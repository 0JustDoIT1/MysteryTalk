## 모듈: 데이터베이스

- 스키마는 마이그레이션 파일로만 변경한다. 관리 콘솔(Studio, pgAdmin 등)에서 직접 바꾸지 않는다.
- 마이그레이션은 한 파일에 한 목적만 담는다. 이미 적용된 마이그레이션 파일은 수정하지 않고 새 파일을 추가한다.
- 접근 제어를 쓰는 DB(Supabase 등)는 새 테이블을 만들 때 RLS 활성화와 정책을 같은 마이그레이션 파일에 넣는다.
- 원격·운영 DB에 적용하는 명령(push, reset, migrate deploy)은 승인 후 실행한다.
- 시드·데이터 import 스크립트는 `--dry-run`을 먼저 실행해 결과를 보고한 뒤 실제 실행한다.
- 컬럼 삭제나 이름 변경처럼 데이터가 사라질 수 있는 변경은, 영향받는 데이터와 되돌리는 방법을 먼저 보고한다.
