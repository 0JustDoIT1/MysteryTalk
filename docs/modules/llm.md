## 모듈: LLM 기능

- 모델명, 제공사, 키는 환경변수로만 관리한다. 코드에 모델명을 하드코딩하지 않는다.
- LLM 호출은 서버(백엔드, Edge Function)에서만 한다. 클라이언트에 LLM 키를 두지 않는다.
- 호출 한도와 월 비용 상한을 코드로 강제한다 (사용자별·일별 제한, 최대 토큰). 상한 값은 `docs/decisions.md`를 따른다.
- 프롬프트는 코드와 분리된 파일이나 상수로 관리하고, 바꿀 때는 버전을 올린다.
- 프롬프트나 모델을 바꾸면 평가 세트를 다시 실행하고, 이전 결과와 비교한 값을 보고한다. 평가 세트를 실행하지 않았으면 "미검증"으로 보고한다.
- 응답은 조회·검색 결과에 있는 정보만 언급하게 하고, 서버에서 결과 밖 정보가 들어갔는지 대조한다.
- 테스트에서는 LLM 호출을 mock 처리한다. 실제 호출 평가는 별도 명령으로 분리하고 승인 후 실행한다.
- 사용자 입력과 응답 로그를 남기는 경우 보관 기간과 개인정보 처리 방식을 PRD에 맞춘다.
