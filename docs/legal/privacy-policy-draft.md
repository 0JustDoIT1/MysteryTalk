# 개인정보처리방침 (초안)

> **법률 검토 전 초안이다(PRD §15).** 실제 문안·시행일·운영자 정보·연락처, 배포처와 AI 제공자(위탁·국외 이전), 연령 확인 수준은 출시 전 법률 검토에서 확정한다. `[ ]`로 표시한 곳은 아직 정하지 않은 값이다. 내용은 2026-11-18 현재 서비스가 실제로 저장하는 것만 적었다(코드·DB 구조 기준).

[운영자 이름](이하 "운영자")은 미스터리톡(이하 "서비스") 이용자의 개인정보를 다음과 같이 처리한다.

## 1. 처리 목적
- 게임 진행과 이어하기: 플레이 기록, 질문과 판정 결과, 답안, 메모, 힌트·단서 상태를 저장해 같은 브라우저 또는 로그인한 다른 기기에서 이어서 하게 한다.
- 로그인: 구글 계정으로 로그인한 이용자를 식별하고 기록을 계정에 보관한다.
- 연령 확인: 만 18세 이상 이용 서비스로, 로그인 이용자의 확인 여부와 시각을 기록한다.
- 서비스 운영: 질문 판정·채점 품질 확인, 일일 질문 한도와 월 AI 비용 관리(악용 방지), 비식별 통계(해결률·평균 질문 수 등).

## 2. 처리하는 항목
| 항목 | 대상 | 비고 |
|---|---|---|
| 게스트 식별 쿠키 | 모든 이용자 | 무작위 값. 서버에는 해시만 저장 |
| 구글 계정 고유 ID | 로그인 이용자 | 이메일·이름·사진은 저장하지 않는다 |
| 로그인 세션 쿠키 | 로그인 이용자 | 서버에는 해시만 저장 |
| 질문 원문, 판정 결과, 정답 답안, 메모 | 모든 이용자 | 입력창에 개인정보를 쓰지 말라고 안내한다 |
| 탐정 이름, 볼륨 등 설정 | 모든 이용자 | 탐정 이름은 화면에만 표시하고 AI에 보내지 않는다 |
| 연령 확인 시각 | 로그인 이용자 | 기기의 확인 결과는 브라우저 저장소에만 둔다 |
| IP 주소의 해시 | 게스트 | 일일 질문 한도 집계용. 날마다 바뀌는 비밀값을 섞은 해시만 저장하고 IP 원문은 저장하지 않는다 |
| AI 호출 기록 | 모든 이용자 | 모델, 토큰 수, 예상 비용, 응답 시간. 질문 내용은 들어 있지 않다 |

음성 질문은 서비스 서버로 보내지 않는다. 브라우저의 음성 인식 기능을 쓰며, 브라우저에 따라 브라우저 제조사가 음성을 처리할 수 있다(처음 쓸 때 안내).

## 3. 보유 기간과 파기
- 게스트 기록: 마지막 플레이 후 30일이 지나면 자동으로 삭제한다.
- 로그인 이용자 기록: 계정 삭제(탈퇴) 즉시 삭제한다.
- 로그인 세션: 30일(쓰면 연장), 만료되면 삭제한다.
- IP 해시 사용량 기록: 30일이 지나면 자동 삭제한다.
- AI 호출 기록: 비용 관리를 위해 [보관 기간] 보관한다. 기록을 지우면 플레이 기록과의 연결은 끊긴다.
- 비식별 통계는 남아 있는 기록으로 계산하므로, 지운 기록은 통계에서도 빠진다.
- 파기는 DB에서 즉시 삭제하는 방식으로 한다. 백업본에 남은 정보는 [백업 보관 기간]이 지나면 덮어써 지워진다.

## 4. 이용자의 권리와 행사 방법
- **삭제**: 설정의 '계정 삭제'(로그인) 또는 '이 브라우저의 기록 지우기'(게스트)로 확인 창 한 번 뒤 즉시 영구 삭제할 수 있다. 계정 삭제 시 연령 확인 기록도 함께 지워진다.
- **연령 확인 다시 하기**: 설정의 '이 기기의 연령 확인 다시 하기'로 기기에 저장된 결과를 지울 수 있다.
- **열람·정정·처리 정지**: [연락처]로 요청하면 [기간] 안에 처리한다.

## 5. 제3자 제공
운영자는 이용자의 개인정보를 제3자에게 제공하지 않는다. 다만 법령에 따른 요청이 있는 경우는 예외로 한다.

## 7. 쿠키와 브라우저 저장소
| 이름 | 용도 | 기간 |
|---|---|---|
| `mt_guest` | 게스트 식별(이어하기) | 30일(쓰면 연장) |
| `mt_session` | 로그인 유지 | 30일(쓰면 연장) |
| `mt_oauth` | 구글 로그인 진행 중 보안 확인 | 10분 |
| 브라우저 저장소 `mt-device` | 연령 확인 결과, 볼륨, 안내 확인 여부 | 지울 때까지 |

쿠키를 막으면 이어하기와 로그인을 쓸 수 없다. 광고·분석용 외부 추적 도구는 쓰지 않는다.

## 8. 만 18세 미만
서비스는 만 18세 이상만 이용할 수 있다. 처음 방문할 때 연령을 확인하고, 18세 미만을 선택하면 이용을 막는다. [실제 연령 검증 수준은 법률 검토 후 확정]

## 9. 안전성 확보 조치
- 식별용 토큰은 해시로만 저장하고, IP 원문은 저장하지 않는다.
- 운영 환경은 HTTPS와 보안 쿠키(Secure·HttpOnly·SameSite)를 쓴다.
- 다른 이용자의 기록에는 접근할 수 없도록 서버가 소유자를 확인한다.
- API 키 등 비밀값은 코드와 로그에 남기지 않는다.
