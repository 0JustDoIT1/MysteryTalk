## 1. 시작 시 팝업 및 이용 안내

- [요구사항] 시작 시 만 18세 이상인지 확인하는 팝업을 표시한다. 살인사건 등 성인 소재 가능성을 안내한다.
- [요구사항] 이용약관 및 개인정보처리방침 링크를 제공하고 각각 새 탭으로 연다.
- [확정] 팝업은 **기기당 최초 1회** 표시하고 결과를 브라우저에 저장한다. 로그인하면 **확인 여부·시각을 계정에 기록**한다(D33).
- [확정] **"아니오"(18세 미만)를 고르면 이용 불가 안내 후 차단**하고 선택 결과를 기기에 기억한다(D60). 완전한 차단이 아님을 인지하며 법률 검토 대상이다.
- [미정] 실제 연령 검증 방식(단순 확인 vs 본인인증)과 게임물 등급분류. 단순 체크박스와 신원 기반 연령 검증을 혼동하지 않는다. → 출시 전 법률 검토(§11).
- [미정] 약관/개인정보처리방침의 실제 문안, 시행일, 연락처, 동의 철회 방식. → 출시 전 검토.

## 2. 메인 페이지

- [요구사항] 메인 배너 일러스트 및 메뉴: **새 스토리 / 이어서 / 공지 / 설정**.
- [요구사항] **한국어 / English** 언어 선택. → [확정] **MVP는 한국어만** 제공하고 영어는 다음 단계(D4). 영어 준비 전까지 **언어 선택 UI는 숨기고**, 화면 문구는 처음부터 번역 파일 구조로 작성한다(D64).
- [v1.1 현재 요구사항] **이어서는 로그인 시만 가능**. 비로그인 플레이 지원 여부 및 로컬 임시 저장은 [미정]. → [변경·확정] **이어서는 게스트도 같은 브라우저에서 이용 가능**하고(게스트 기록은 서버에 보관, 브라우저 쿠키로 연결), 로그인하면 다른 기기에서도 이어할 수 있다(D29). 변경 이유: 로그인을 '기록 백업' 용도로 정의한 §3·§10과의 충돌 해소.
- [확정] '이어서'에서는 진행 중인 사건들을 골라 이어한다(사건별 진행, D54).
- [확정] 공지는 저장소 파일로 관리하고 배포 시 갱신한다(관리자 화면 없음, D41).
- [확정] 배너·아트는 상업 이용 가능한 무료 에셋(CC0 등) 한 계열을 기반으로 하고, 사건별 소품·메인 배너만 직접 제작 또는 의뢰한다. 에셋마다 출처·라이선스를 기록한다(D67). 세부 화풍·팔레트는 SPEC 단계.

## 3. 설정

- [요구사항] 언어 설정: 한국어 / English. → [확정] 영어 준비 전까지 숨김(D4, D64).
- [요구사항] 사운드/음성 설정. → [확정] **BGM·효과음 개별 볼륨**, TTS 없음(D39).
- [요구사항] 주인공(탐정) 이름 설정. → [확정] **1~12자, 기본 이름 제공, 금칙어 필터**. 이름은 **화면 고정 문구에만 표시하고 AI에 전달하지 않는다**(D40).
- [요구사항] 로그인: 기록 백업 용도. → [확정] **구글 로그인**(D30).
- [요구사항] 버그 제보. → [확정] **외부 폼**으로 받는다(D41). 수집하는 진단 정보는 SPEC 단계.
- [요구사항] 뒤로가기/돌아가기.
- [확정] 설정은 기기 또는 계정에 저장한다(D53).

## 4. 새 스토리 / 사건 선택

- [목표] **초기 공개 사건 10건**, 확장 목표 30건.
- [요구사항] **튜토리얼 사건 1개**(본편과 별도, 등급·기록 제외, D24).
- [요구사항] 장르: 전체 / 미스터리 / 공포 / 범죄 등. → [확정] 최종 분류는 **전체 / 미스터리 / 공포 / 범죄**, 사건당 복수 태그 가능(D50).
- [요구사항] 상태 구분: **미해결 / 해결**. 부분 해결(D등급) 사건은 **미해결 + 최고 등급 D**로 표시한다(D70).
- [요구사항] 사건 선택 시 하단에 **한 줄 요약** 표시 및 **시작 버튼** 제공.
- [확정] 사건 카드에 난이도, **수위 등급, 콘텐츠 태그**(예: 살인, 공포 분위기), 상태, **최고 등급·달성 회차·총 플레이 횟수**를 표시한다(D18, D36).
- [확정] 순서: 첫 방문 시 **튜토리얼을 권장하되 건너뛸 수 있고**, 본편 10건은 **잠금 없이 자유 선택**. 목록은 쉬운 순(D55).
- [확정] 난이도는 **사건 고유 난이도**다(D10).
- [요구사항] 실화 기반 또는 영화/만화에서 영감을 받은 사건은 출처·표현 방식 검토. → [확정] 실화·영화·만화에서는 **발상만 빌리고 완전 창작**한다. 실명·실제 장소·피해자를 특정할 수 있는 세부 금지, 작품의 반전·전개 복제 금지(D34).
- [확정] 제작·검수 절차: **사건 문서 → 개연성 점검표 → 평가 질문 30개 이상으로 AI 판정 측정 → 플레이테스트 → 공개**. 사용자가 최종 승인하고 Claude는 초안·점검·측정을 보조한다(D65).
- [확정] 사건 내용을 고치면 **진행 중 세션에도 새 내용을 적용하고 세션에 사건 버전을 기록**한다. 진상이 바뀌는 큰 수정은 새 버전으로 내고 기존 진행자에게 안내한다(D59).
- [확정] **출시용 본편 사건 데이터는 비공개 저장 공간**에 두고 배포 시 주입한다. 공개 저장소에는 튜토리얼·샘플 사건만 둔다(D85).
- [미정] 영어 동시 제공 시점, 사건 10건 제작 일정. → 한국어 MVP 검증 후.

## 5. 게임 규칙 및 질문 시스템 (핵심)

### 5.1 플레이 목표
- [요구사항] 질문으로 사건의 **진상**을 밝히며 가능한 적은 질문으로 해결할수록 유리한 평가를 받는다.
- [요구사항] 난이도: **쉬움 / 보통 / 어려움**(사건 고유, D10).
- [요구사항] 점수 또는 랭크: **S / A / B / C / D / F**(§8).
- [확정] 질문 수는 **넉넉한 서버 안전 상한 + 사용 질문 수로 점수 차등**(D9). 사건별 **기준 질문 수 B**의 기본값은 **쉬움 20 / 보통 30 / 어려움 40**이고 사건마다 조정할 수 있다. 서버 상한은 **3B**(60/90/120)이며 도달하면 질문은 불가하고 정답 제출만 가능하다(D49).

### 5.2 질문과 대답
- [요구사항] 사용자는 원칙적으로 **예/아니오로 답할 수 있는 질문**을 입력한다.
- [요구사항] 응답 범주: **예 / 아니오 / 그럴 수도 / 관계없음**.
- [확정] 위 4종과 별개로 **'다시 질문해 주세요' 상태**를 둔다. 복합 질문, 열린 질문(누가·왜·어떻게), 정답을 직접 요구하는 질문, 의도가 불명확한 질문, 욕설·혐오 표현, AI 조작 시도가 대상이며 **사유별 고정 안내**를 보여 준다(D1, D57).
- [확정] '그럴 수도'는 사건 사실에 근거가 있고 **부분적·조건부로만 맞을 때만** 쓴다. 사건 데이터에 부분 사실을 명시한다(D2).
- [확정] 사건 설정에 정의되지 않은 세부 사항은 **관계없음**으로 답한다. 진상과 관련된데 빠진 사실은 로그로 모아 사건 데이터를 보강한다(D3).
- [확정] "OO가 범인인가요?"처럼 핵심 정답을 직접 확인하는 단일 질문은 **그대로 판정**한다. 진상 전체를 한 번에 묻는 질문은 대부분 복합 질문이라 '다시 질문'으로 처리된다(D7).
- [확정] 질문 길이는 **2~100자**(D8). 마이크로 입력한 문장도 같은 규칙을 적용한다.
- [확정] **차감 규칙**(D68): 예·아니오·그럴 수도·관계없음은 **차감**. 다음은 **미차감**: '다시 질문', 정규화(공백·문장부호) 후 **같은 문장**의 재질문(이전 답 재표시, D5), AI 판정 실패(D6).
- [확정] AI 판정이 실패하면(오류·지연·비용 한도) **미차감**, 안내 후 같은 질문을 재시도할 수 있다. 같은 요청을 다시 보내도 한 번만 처리한다(D6).
- [확정] 의미가 같지만 표현이 다른 질문은 새 질문으로 판정한다(D5).
- [확정] AI 조작 시도는 판정을 바꿀 수 없게 하고, 반복되면 호출을 제한한다(D57).
- [확정] 입력창에 개인정보 입력 금지 안내를 표시한다(D37).
- [확정] [목표] **질문 판정 요청의 95%가 5초 이내**에 응답한다. 대기 중에는 '수사 중…' 연출을 보여 준다(D87).
- [원칙] 사용자에게 정답 원문/숨겨진 사건 해설을 직접 노출하는 응답을 방지한다.

### 5.3 질문 기록
- [요구사항] **현재 세션에서 질문한 문장과 AI 대답을 조회하는 탭** 제공.
- [확정] **순번·질문·판정 + 판정별 필터**. '다시 질문'은 순번 없이 표시한다(D48).
- [확정] 질문 원문은 **기록 보관 기간과 동일하게 보관**(게스트 30일, 로그인 탈퇴 시 삭제). 분석용은 비식별 형태만 남긴다(D37). 공개 범위는 본인만.
- [원칙] 동일 요청 재전송과 동시 요청은 서버에서 정합성 유지. 멱등성 키 계약은 SPEC에서 확정.

### 5.4 사건 설명과 수첩
- [확정] 사건 시작 시 **짧은 도입 이야기**를 보여 주고, 수첩의 **수사 자료 탭**에서 개요(일시·장소·피해자), 관련자 목록, 확인된 타임라인을 언제든 다시 볼 수 있다(D77).
- [확정] 수첩: 수사 자료, 획득 단서(NPC 진술 포함), 질문 기록, **사건별 자유 메모 1개**(이어하기에 포함, AI에 전달하지 않음, D62).
- [확정] 플레이 중에는 **점수·등급을 숨기고 진행 수치만** 보여 준다: 질문 수/기준, 열람한 힌트 수, 남은 제출 기회(D76).

## 6. 현장 조사: 쯔꾸르풍 단서 탐색 (보조)

- [요구사항] 사건 배경의 현장을 탐색하는 **2D 이동 화면**.
- [요구사항] 장소 내 물건 조사 및 **단서 발견**.
- [확정] 맵 구조: **여러 맵 전환**(구역 = 맵, 맵 사이 출입구가 해금 지점). 위치는 (맵, 좌표)로 저장·검증한다(D56).
- [확정] 구역 해금: **사건마다 단서 해금 구역과 사실 해금 구역을 섞어 설계**한다(D26).
  - 단서 해금: 특정 단서를 획득하면 열린다(서버가 결정적으로 판단).
  - 사실 해금: AI가 해당 사실을 근거로 **'예'** 판정을 내리고 서버 키워드 검사도 통과하면 열린다('그럴 수도'는 열지 않음, D74).
  - **사실 해금 구역은 연결된 힌트를 열면 함께 열린다**(AI 판정 누락 보완).
- [확정] **단서는 선택**이다. 단서를 찾지 않았거나 구역이 닫혀 있어도 질문과 정답 제출이 가능하다(D27). 현장 조사는 점수에 반영하지 않는다(D11).
- [확정] NPC: **고정 대사 NPC 사건당 0~2명, 대사 1~3줄**, 심문·AI 대화 없음. 대사도 단서 규칙(진상 직접 언급 금지, 사실 목록에 기록)을 따른다(D28). 처음 말을 걸면 **수첩에 '진술' 단서로 기록**되고, 놓친 단서·단서 해금 조건에 포함된다(D75).
- [확정] 맵 크기·구역 수·조사 대상·단서 수는 **사건마다 자유**(D51).
- [확정] 모바일은 **가상 방향키·터치 조사**를 지원한다(D42). ⚠ 여러 맵 전환과 겹쳐 작업 범위가 크다.
- [확정] 힌트·구역이 열리면 **짧은 알림**을 띄운다. 사실 해금 구역은 어떤 사실 때문에 열렸는지 밝히지 않는다(D81).
- [미정] 이동 키, 단서 수첩 UI 세부, 이미 본 사물 재조사 동작. → SPEC 단계에서 UI 시안과 함께.
- [원칙] 2D 탐색은 **주요 질문형 추리를 돕는 수단**이며 전투, 복잡한 RPG 성장 및 NPC 자유 심문을 임의 추가하지 않는다.

## 7. 힌트

- [요구 방향] 힌트 사용 시 최종 점수 차감 검토. → [확정] 열람한 힌트만 감점(아래).
- [확정] **기준 질문 수 B의 1/3마다 순서대로 해금**(B/3, 2B/3, B번째 질문, 소수점은 올림)하고, **실제로 열람한 힌트만 감점**한다(해금과 열람 구분, D15, D17).
- [확정] 힌트 버튼에 **"다음 힌트까지 질문 N개"**를 표시한다(D81).
- [확정] 감점량은 §8 점수 공식을 따른다(D16).
- [확정] 힌트 열람은 같은 요청이 두 번 와도 한 번만 처리한다(이중 감점 방지).
- [미정] 힌트 내용 작성·검수는 사건 제작 절차(D65)에 포함, 다국어는 영어 단계에서.

## 8. 정답 제출, 채점 및 엔딩

- [요구사항] 사건 진상을 직접 제출한다. → [확정] **자유 서술 한 칸, 10~300자**(D71, D79). 제출 전에는 정답 요소의 개수·종류를 드러내지 않는다(D84).
- [요구사항] **핵심 요소(키워드)가 모두 반영되어야 완전 통과**한다.
- [확정] 채점: **키워드 + AI 하이브리드**. 요소마다 키워드 검사와 AI 의미 판정을 함께 보고, 둘이 일치하면 확정, 엇갈리면 미확정이다(D20).
- [확정] 제출 기회는 **3회**(D12).
  - 일부 요소만 맞으면 **오답 처리**(제출 1회 소모)하고 **"아직 진상이 아닙니다" + "3개 중 2개"처럼 맞힌 개수와 전체 개수**를 보여 준다. 개수는 확정 일치만 센다(D13, D21, D84).
  - 미확정 요소만 있으면 **제출 기회를 쓰지 않고 재작성을 요청**한다(최대 2회, 이때는 개수를 보여 주지 않음). 2회를 넘으면 AI 판정을 따른다(D23).
  - 오답 후에도 **질문을 계속할 수 있다**(D22).
  - 채점 중 AI가 실패하면 **제출 기회·감점 없이 같은 답안을 재시도**한다(D73).
- [요구사항] 사건 해결 후 **전체 사건 내용/진상 해설**을 보여준다. → [확정] **F·부분 해결·포기에도 해설을 공개**한다(D19).
- [요구사항] S/A/B/C/D/F 등급으로 평가한다. → [확정] 기준은 §8.1.
- [확정] 엔딩 화면: 진상 해설 + **점수 내역 + 정답 요소별 충족 여부 + 미끼였던 단서·놓친 단서**(D61).
- [확정] **수사 포기**: 사건 메뉴에 포기 버튼과 확인 창("포기하면 F가 기록돼요")을 두고, 포기 후 해설을 공개한다(D80).

### 8.1 점수 공식 [잠정 수치] (D16)
감점형. B = 사건별 기준 질문 수, q = 차감된 질문 수.

| 항목 | 감점 |
|---|---|
| 기준 초과 질문 | max(0, q − B) × 2, 최대 40 |
| 힌트 열람 | 1번째 10, 2번째 15, 3번째 20(누적 최대 45) |
| 오답 제출 | 1회당 10(해결 전 최대 2회) |

| 등급 | 조건 |
|---|---|
| S / A / B | 해결 시 점수 ≥ 90 / ≥ 80 / ≥ 70 |
| C | 해결 시 최저 등급(70 미만) |
| D | **부분 해결**: 제출 3회 실패 + 마지막 제출이 필수 요소 **절반 이상** 충족(D69) |
| F | **미해결**: 제출 3회 실패 + 충족 절반 미만, 또는 **포기**(D14, D69) |

- 예) 보통(B=30), 질문 34, 힌트 1, 오답 0 → 100 − 8 − 10 = 82 → A.
- 감점량·등급 컷은 플레이테스트와 통계(D47)로 조정한다. 현재 수치에서는 힌트 1개를 열어도 S(90)가 가능하며, 의도 여부를 플레이테스트에서 확인한다.

### 8.2 기록
- [확정] 재플레이는 새 세션으로 시작한다. 사건별로 **최고 등급 + 최고 등급 달성 회차 + 총 플레이 횟수**를 기록한다(예: "최고 S · 3회차 달성 · 총 4회", D18).
- [확정] 공유·랭킹 없이 **개인 기록만** 제공한다(D43).

## 9. 마이크 질문

- [요구사항] 마이크로 질문할 수 있는 기능.
- [권장 검토 → 확정] 음성 인식 결과를 사용자가 확인하고 **전송할 때에만** 질문으로 처리.
- [확정] **브라우저 내장 음성 인식**을 사용하고, 지원 브라우저에서만 마이크 버튼을 보여 준다. 인식된 문장을 입력창에 넣고 **플레이어가 확인·수정한 뒤 전송**한다(D38).
- [확정] 우리 서버는 음성을 받지도 저장하지도 않는다. 브라우저 제조사가 음성을 처리할 수 있다는 사실은 안내한다(D38).

## 10. 로그인·저장·이어하기

- [요구사항] 로그인은 **기록 백업** 용도로 제공. → [확정] **구글 로그인**(D30).
- [v1.1 요구사항] 메인 **이어서는 로그인 사용자만** 이용 가능. → [변경·확정] **게스트 플레이 허용**, 같은 브라우저에서 이어하기(D29). 변경 이유: 로그인을 '기록 백업' 용도로 정의한 요구사항과의 충돌 해소.
- [확정] 로그인하면 게스트 기록을 **계정으로 자동 이전**한다(D31). 같은 사건의 진행 중 기록이 양쪽에 있으면 **마지막 활동이 더 최근인 쪽을 유지**하고 다른 쪽은 F 없이 삭제한다. 끝난 기록은 모두 합치고 **회차는 플레이 시각 순으로 다시 매긴다**(D82).
- [확정] 보관 기간: 게스트 기록은 **마지막 플레이 후 30일** 서버 보관 후 삭제, 로그인 기록은 탈퇴 시 삭제(D32).
- [확정] 이어하기 복원 범위: **전부** — 질문 기록, 단서, 열린 구역, 맵과 위치, 힌트 해금·열람, 제출 횟수, 감점 요소, 메모(D53, D62).
- [확정] 여러 사건을 **사건별로 각각 진행**한다(사건당 진행 중 기록 1개, D54).
- [미정] 계정 탈퇴·데이터 삭제 절차의 세부. → 개인정보 문안과 함께 출시 전.
- [원칙] 사용자별 세션 데이터 분리, 중복 처리와 재접속 복원 검증.

## 11. 공지·운영·콘텐츠 안전

- [요구사항] 공지 메뉴 및 버그 제보 제공. → [확정] **관리자 화면 없이 시작**: 공지는 저장소 파일, 버그 제보는 외부 폼(D41).
- [확정] 표현 수위: **사건별 수위 등급 2단계**(D35).
  - **보통**: 살인·사망을 다루되 묘사는 검시 소견 수준, 긴장감 있는 연출. 사망 없는 사건도 '보통' + 태그(예: 사망 없음)로 구분.
  - **강함**: 동기·과정을 더 직접 서술, 공포 분위기 연출.
  - **공통 금지**: 신체 훼손 그림, 범행 절차의 구체적 재현, 피해자 희화화, 점프 스케어.
- [확정] 사건 카드에 **콘텐츠 태그와 수위 등급**을 표시하고 장르 필터와 연결한다(D36).
- [확정] 운영 방식: **무료 운영 + 월 비용 상한 1만 원 이하**(AI·서버 합산, D44, D46). 상한 도달 시 **새 질문만 차단하고 정답 제출은 허용**하며, 월 상한의 일부(예: 10%)를 **제출 채점 예비 예산**으로 따로 둔다(D72). 수익화는 이용 데이터를 본 뒤 재검토. ⚠ 사용자가 늘면 월중 질문이 일찍 막힐 수 있다.
- [확정] 악용 방지: 게스트는 **IP당 일일 질문 한도**, 로그인하면 계정 기준으로 한도를 완화한다(D58). 한도에 걸리면 **질문만 차단하고 정답 제출은 허용**하며 로그인을 안내한다. **튜토리얼은 IP 한도에서 제외**하되 튜토리얼 자체 질문 상한을 둔다(D83). 한도 수치는 비용 측정 후 정한다.
- [확정] 플레이 통계: **비식별 지표만 자체 DB에서 집계**(해결률, 평균 질문 수, 힌트 사용률, '다시 질문' 비율), 외부 분석 도구 미사용(D47).
- [출시 전 검토 필요] 게임물 등급분류와 연령 확인 의무 수준, 음성 데이터(브라우저 제조사 처리) 고지, 실화·창작물 영감의 명예훼손·저작권 검토, 약관·개인정보처리방침 문안.
- [원칙] 실제 사건·영화·만화의 법적/윤리적 위험을 출시 전 검토한다.

## 13. 개발 순서 (D86)

핵심 루프를 먼저 끝까지 검증한다.

1. 기반: 스캐폴딩, DB, 게스트 세션, CI
2. 질문 판정 + 평가 세트(로컬 AI)
3. 정답 제출·채점·점수·힌트·엔딩 → **튜토리얼 + 사건 1건, PC, 텍스트만으로 끝까지 검증**
4. 현장 조사: 여러 맵, 구역 해금, NPC
5. 구글 로그인, 기록 이전, 이어하기
6. 모바일 터치, 마이크, 사운드, 설정
7. 비용·악용 방지, 통계, 공지
8. 나머지 사건 제작(§4 제작 절차)
9. 배포, 법률 검토, 공개

- 3단계가 끝나는 시점에 일정과 범위(특히 여러 맵·모바일·10건 동시 공개)를 다시 점검한다.
