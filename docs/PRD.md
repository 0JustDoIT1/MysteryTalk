## 1. 시작 시 팝업 및 이용 안내

- [요구사항] 시작 시 만 18세 이상인지 확인하는 팝업을 표시한다. 살인사건 등 성인 소재 가능성을 안내한다.
- [요구사항] 이용약관 및 개인정보처리방침 링크를 제공하고 각각 새 탭으로 연다.
- [미정] 팝업을 최초 방문에만 노출할지, 매 방문/매 로그인 시 노출할지.
- [미정] 확인 결과 저장 위치·보존기간·동의 철회 방식.
- [미정] 실제 연령 검증 방식과 등급분류/콘텐츠 경고 정책. 단순 체크박스와 신원 기반 연령 검증을 혼동하지 않는다.
- [미정] 약관/개인정보처리방침의 실제 문안, 시행일, 연락처 및 운영 정책. 법령/스토어 규정은 출시 전 별도 검토한다.

## 2. 메인 페이지

- [요구사항] 메인 배너 일러스트 및 메뉴: **새 스토리 / 이어서 / 공지 / 설정**.
- [요구사항] **한국어 / English** 언어 선택.
- [현재 요구사항] **이어서는 로그인 시만 가능**. 비로그인 플레이 지원 여부 및 로컬 임시 저장은 [미정].
- [미정] 배너 아트 스타일 세부, 공지 관리 방식, 로그인 진입 UX, 언어 선택 저장 정책.

## 4. 새 스토리 / 사건 선택

- [목표] **초기 공개 사건 10건**, 확장 목표 30건.
- [요구사항] **튜토리얼 사건 1개**.
- [요구사항] 장르: 전체 / 미스터리 / 공포 / 범죄 등(최종 분류 목록 [미정]).
- [요구사항] 상태 구분: **미해결 / 해결**.
- [요구사항] 사건 선택 시 하단에 **한 줄 요약** 표시 및 **시작 버튼** 제공.
- [요구사항] 실화 기반 또는 영화/만화에서 영감을 받은 사건은 출처·표현 방식 검토.
- [미정] 10건에 튜토리얼 포함 여부, 사건별 난이도 선택 여부, 추천 사건 순서.
- [미정] 실화 기반 사건의 개인정보/명예훼손 위험 검토 방식과 창작물 저작권 처리. 영화·만화의 원문/전개/반전 복제 금지.
- [미정] 사건 데이터 제작·검수 프로세스, 번역·한국어/영어 동시 제공 시점.

## 5. 게임 규칙 및 질문 시스템 (핵심)

### 5.1 플레이 목표
- [요구사항] 질문으로 사건의 **진상**을 밝히며 가능한 적은 질문으로 해결할수록 유리한 평가를 받는다.
- [요구사항] 난이도: **쉬움 / 보통 / 어려움**. 난이도별 통과 질문 수 또는 평가 기준을 달리한다.
- [요구사항] 점수 또는 랭크: **S / A / B / C / D / F**.
- [미정] 질문 수 **하드 제한**인지, 무제한 질문 + **점수 감점**인지.
- [미정] 난이도가 사건 난이도인지, 플레이어가 선택하는 모드인지.

### 5.2 질문과 대답
- [요구사항] 사용자는 원칙적으로 **예/아니오로 답할 수 있는 질문**을 입력한다.
- [요구사항] 응답 범주: **예 / 아니오 / 그럴 수도 / 관계없음**. ‘그럴 수도’는 반반·조건부/불확실한 경우의 의도.
- [미정] 복합질문, 부정문, 모호한 질문, 정답을 직접 요구하는 질문의 판정 규칙.
- [미정] 예/아니오로 답할 수 없는 질문의 별도 재작성 안내 및 질문 횟수 차감 여부.
- [미정] 동일/의미상 중복 질문, 질문 오류 및 재시도 시 횟수 정책.
- [미정] 답변의 일관성 확보·오판 처리 방식과 사건별 사실 데이터 구조.
- [원칙] 사용자에게 정답 원문/숨겨진 사건 해설을 직접 노출하는 응답을 방지한다.

### 5.3 질문 기록
- [요구사항] **현재 세션에서 질문한 문장과 AI 대답을 조회하는 탭** 제공.
- [미정] 기록에 시간·횟수·검색/필터를 포함할지, 저장 기간 및 공개 범위.
- [원칙] 동일 요청 재전송과 동시 요청은 서버에서 정합성 유지. 멱등성 키 계약은 설계 시 확정.

## 6. 현장 조사: 쯔꾸르풍 단서 탐색 (보조)

- [요구사항] 사건 배경의 현장을 탐색하는 **2D 이동 화면**.
- [요구사항] 장소 내 물건 조사 및 **단서 발견**.
- [미정] NPC 등장 여부. 현재 선호는 **NPC 없는 탐색**이고, NPC 심문은 메인 기능이 아니다.
- [미정] 맵 수·크기·연결 방식, 이동 키/터치 지원, 충돌·상호작용 키.
- [미정] 탐색 개방 시점(언제든 가능/질문 진행에 따라 해금), 단서 필수 여부.
- [미정] 조사 오브젝트 수·실제 단서 수, 사건별 맵 제작 범위.
- [미정] 단서의 UI·수첩 저장 형식·이미 본 사물 재조사 동작.
- [원칙] 2D 탐색은 **주요 질문형 추리를 돕는 수단**이며 전투, 복잡한 RPG 성장 및 NPC 자유 심문을 임의 추가하지 않는다.

## 7. 힌트

- [검토 중] 사건당 **약 3개**의 단계별 힌트.
- [미정] 힌트를 처음부터 직접 열 수 있는지, 일정 질문 수마다 순차 해금할지, 둘을 조합할지.
- [미정] **해금**과 **실제 열람**을 구분할지.
- [요구 방향] 힌트 사용 시 **최종 점수 차감** 검토.
- [미정] 각 힌트의 감점량, 난이도별 차이, 힌트 사용/미사용의 등급 상한.
- [미정] 힌트 내용 작성·검수 및 다국어 정책.

## 8. 정답 제출, 채점 및 엔딩

- [요구사항] 사건 진상을 직접 제출한다.
- [요구사항] **핵심 요소(키워드)가 모두 반영되어야 완전 통과**한다. 단순 단어 포함 여부가 아니라 의미상 충족 기준 검토 필요.
- [요구사항] 사건 해결 후 **전체 사건 내용/진상 해설**을 보여준다.
- [요구사항] S/A/B/C/D/F 등급으로 평가한다.
- [미정] 정답 채점 방식: 규칙, LLM 의미 판정, 혼합형 및 오탐 방지.
- [미정] 부분 정답 처리, 제출 횟수, 실패 시 재시도, 오답 피드백 범위.
- [미정] 질문 수/정답 충족도/힌트 차감/난이도별 기준을 결합하는 **최종 점수 공식과 등급 컷**.
- [미정] F의 발생 조건, 사건 완료 기록 갱신 방식, 최고 점수 유지 여부.

## 9. 마이크 질문

- [요구사항] 마이크로 질문할 수 있는 기능.
- [미정] 브라우저 STT vs 외부 음성 인식 서비스, 지원 브라우저와 권한 UX.
- [미정] STT 오인식 수정 UI, 음성 데이터 전송/저장 여부, 비용 정책.
- [권장 검토] 음성 인식 결과를 사용자가 확인하고 **전송할 때에만** 질문으로 처리.

## 10. 로그인·저장·이어하기

- [요구사항] 로그인은 **기록 백업** 용도로 제공.
- [현재 요구사항] 메인 **이어서는 로그인 사용자만** 이용 가능.
- [미정] 게스트 플레이 허용 여부, 비로그인 상태에서 현재 세션 중단 시 처리.
- [미정] 인증 수단, 개인정보 수집 항목, 계정 탈퇴·데이터 삭제, 세션 보존 기간.
- [미정] 이어하기 복원 범위: 질문 로그/획득 단서/맵 위치/힌트/점수/설정.
- [원칙] 사용자별 세션 데이터 분리, 중복 처리와 재접속 복원 검증.

## 11. 공지·운영·콘텐츠 안전

- [요구사항] 공지 메뉴 및 버그 제보 제공.
- [미정] 공지 게시·수정 방식, 신고 관리, 운영자 도구 범위.
- [미정] 성인 소재·폭력·공포 표현 수위 및 사건별 경고 방식.
- [미정] 서비스 공개 범위, 운영 예산, AI 질문 비용 상한, 악용 방지 정책.
- [원칙] 실제 사건·영화·만화의 법적/윤리적 위험을 출시 전 검토한다.

## 13. 결정 대기 목록 (우선순위)

1. 질문 횟수 하드 제한 여부와 난이도별 기준

3. 정답 제출·부분 정답·재도전 정책

7. 로그인/게스트/이어하기 및 저장 정책
8. 나이 확인·콘텐츠 등급·약관/개인정보·실화/창작물 출처

## 14. 변경 관리

- 이 문서는 아직 최종 PRD가 아니라 **기획 뼈대**다.
- [미정] 항목은 Claude Code가 구현 편의를 위해 임의 결정하거나 확정 표시하지 않는다.
- 변경 시 제안 이유, 영향 범위, 대안, 추천안을 사용자에게 보고한 뒤 승인받는다.
- 승인된 정책만 문서에 반영하며, 임의로 기존 요구사항을 삭제하지 않는다.
