아래 작업을 CLAUDE.md 규칙에 따라 수행한다.

$ARGUMENTS

진행 규칙:
- 시작 전에 현재 브랜치와 커밋하지 않은 변경을 확인한다.
- 작업 내용에 "범위", "완료 기준", "새 패키지" 항목이 없으면 다음과 같이 처리한다.
  - 범위: 목표에 직접 필요한 파일로 한정하고, 수정할 파일 목록을 먼저 보여준다.
  - 완료 기준: 내가 이해한 완료 기준을 2~3줄로 적고 시작한다.
  - 새 패키지: 금지로 간주한다. 필요해 보이면 멈추고 `.claude/commands/pick-lib.md`의 비교 형식으로 제시한다.
- 완료 기준을 하나씩 확인하고, CLAUDE.md 9장 형식으로 결과를 보고한다.
